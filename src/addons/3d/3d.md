# 3D

`sonic-3d` — viewer **Three.js** (glTF / GLB), caméra orbit / perspective / ortho, outputs dataProvider paresseux.

Import opt-in (hors bundle `functional`) :

<sonic-code language="javascript">
  <template>
import "@supersoniks/creative-stack/3d";
import type {
  Sonic3dConfig,
  Sonic3dOutput,
  Sonic3dAsset,
  Sonic3dCameraMode,
} from "@supersoniks/creative-stack/3d";
  </template>
</sonic-code>

CDN (after the core): `creative-stack-3d.bundle.js` — see [CDN addons](#docs/_getting-started/cdn-addons.md/cdn-addons).

## Démo (modèle CDN)

`DamagedHelmet` (Khronos, jsDelivr). Orbit · zoom · pan · survol highlight · pick · double-clic = recentrer. Sans `src` : cube de démo. Molette : zoom tant qu’il reste de la marge ; aux bornes `minDistance` / `maxDistance`, le scroll page reprend.

## Form auto-bind (`formDataProvider`)

Comme `sonic-shader` : si `dataProvider` (ou un ancêtre `formDataProvider`) contient des champs aux **mêmes noms** que l’API, ils pilotent le viewer sans JS.

| Champ form | Effet |
|------------|--------|
| `src` / `asset` | charge le modèle |
| `camera` | mode caméra |
| `fov` / `exposure` | optique |
| `autoRotate` | rotation orbit |
| `minDistance` / `maxDistance` | bornes zoom orbit |
| `minPolar` / `maxPolar` | bornes verticale (degrés) |
| `yaw` / `pitch` / `distance` | position orbit sphérique |

Conseil : séparer `out-data-provider` du form. Les entrées pures (`fov`, `exposure`, `autoRotate`, `src`…) ne sont jamais réécrites en out sur un DP partagé. `yaw` / `distance` / `pitch` restent publiables ; un changement manuel d’orbit coupe `autoRotate`.

Gate paresseuse : un `sonic-audio-input name="yaw"` **ne** déclenche **pas** la publication out (seul un lecteur sur `ready` / `frame` / `cam*` / `hit*`… le fait).

## Sortie / dataProvider

Entrée : champs ci-dessus. Sortie (`Sonic3dOutput`) : `cam*` / `target*` / `distance` / `yaw` / `pitch` / `pointer*` / `ready` / `hit*`… With `frame-out` (or a listener on `frameUrl` / `snapshot`): lazy JPEG canvas capture → `frameUrl` + `snapshot` (`SonicMediaRef`). Event `out`. Publication **paresseuse**.

## Caméras

| `camera` | Usage |
|----------|--------|
| `orbit` (défaut) | Produit / modèle isolé — orbit + pan, polar limité |
| `perspective` | Scène libre + pan |
| `ortho` | Plans techniques / UI 3D |

## Asset neutre (HF plus tard)

```ts
type Sonic3dAsset = {
  kind?: "gltf" | "glb" | "obj" | "ply" | "url";
  url?: string;
  blob?: Blob;
};
```

Le viewer lit `asset` ou `src` depuis le DP — la source (fetch, upload, HF) n’est pas couplée.

## Attributs

| Attribut | Rôle |
|----------|------|
| `src` | URL glTF / GLB (vide → démo) |
| `camera` | `orbit` \| `perspective` \| `ortho` |
| `fov` | FOV perspective (défaut 45) |
| `exposure` | Tone mapping (défaut 1) |
| `min-distance` | Zoom orbit mini (défaut 0.5) |
| `max-distance` | Zoom orbit maxi (défaut 50 ; `0` = ∞) |
| `min-polar` / `max-polar` | Angle vertical en **degrés** (défaut 8–172) |
| `auto-rotate` | Rotation orbit |
| `fit` | Fit bbox après load (défaut true) |
| `pick` | Survol highlight + clic → event `pick` + `hit*` ; double-clic = fit |
| `play` / `play-on-hover` | Boucle RAF |
| `play-offscreen` | Garde RAF / runtime hors viewport (pont live `#id`) |
| `release-offscreen` | Dispose renderer hors viewport (défaut true) sauf si `play-offscreen` / consommateur live |
| `damping` | Inertie OrbitControls (défaut `0.08`, `0` = off) |
| `dpr-max` | Cap devicePixelRatio (défaut 2) |
| `dataProvider` / `out-data-provider` | Entrée / sortie |
| `out-interval` | Throttle publication ms (défaut 80) |
| `frame-out` | Publishes `frameUrl` + `snapshot` (canvas JPEG) for shader chaining |
| `snapshot-interval` | Canvas capture throttle ms (default 250) |

## Shader bridging

No shared WebGL context between `sonic-3d` and `sonic-shader`.

| Need | Bridge |
|------|--------|
| **Live post** | `channel0="#plateau"` on `sonic-shader` (or DP `{ element }`) — canvas copy each frame via `SonicFrameSource` |
| **Export / HF / freeze** | `frame-out` → `frameUrl` + `snapshot` (`SonicMediaRef` JPEG). Clone with `cloneMediaRef` before holding a frame |

```html
<!-- Live -->
<sonic-3d id="plateau" play auto-rotate …></sonic-3d>
<sonic-shader channel0="#plateau" image="…" play></sonic-shader>

<!-- Export / freeze -->
<sonic-3d frame-out out-data-provider="view3d" snapshot-interval="250" …></sonic-3d>
```

Demo: [Visual stack — 3D → shader live](#docs/_misc/visual-stack.md/visual-stack).

Un `sonic-shader` / `sonic-webgpu` qui pointe `#id` s’enregistre via `registerFrameConsumer` : le 3D **continue hors viewport** (pas de dispose). Option explicite : `play-offscreen`.

### Arrêt net

`el.stopMotion()` coupe `autoRotate` et l’inertie OrbitControls. Quand la caméra est immobile depuis ~8 frames : event `rest` + champ out `moving: 0|1`. Attribut `damping` (défaut `0.08`, `0` = off).

## Post FX (in-viewer)

When `post-image` is set, the scene renders to an offscreen target with a **depth texture**, then ShaderToy-style passes run inside the same Three context (`post-buffer-a`…`post-image`). Same GLSL as `sonic-shader` (`mainImage`, `iChannel0–3`, `uParam0–3`, `sonicLinearDepth`).

| Channel token | Source |
|---------------|--------|
| `scene` (default ch0) | Color render target |
| `depth` | Depth texture from the scene pass |
| `buffer-a`…`d` | Ping-pong buffers |
| URL / `#id` | External texture (same as shader live bridge) |

```html
<sonic-3d
  post-image="…GLSL…"
  post-image-ch0="scene"
  post-image-ch1="depth"
  param0="0.5"
  post-scale="1"
></sonic-3d>
```

Demo: [Visual stack — post depth edges](#docs/_misc/visual-stack.md/visual-stack).

Pick / orbit still use scene geometry; `frame-out` captures the **final** canvas after post.
